# TNO-system-diagrams
Diagrams for visualizing the orbits of trans-Neptunian object (TNO) systems as seen from Earth and from their north poles.

Much of the Python code was initially generated by ChatGPT, but I have subsequently edited them by hand (making corrections, annotations, colors, fontsizes, cleanup, etc.). The Python scripts are intended to be run through command-line. Executing the Python code prompts a "Enable dark mode? (y/n)" input from the user, before creating and saving the plot.
